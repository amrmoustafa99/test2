# Clinic Booking System

A clinic booking website that doctors' receptionists could use: manage doctors, patients and appointments.

This is the web version of a C++ console project. The logic is the same: `Person` → `Doctor` / `Patient`, `Appointment`, and a `ClinicSystem` class that holds the data.

## Features
- Add and view doctors
- Register and view patients (age validation)
- Book appointments (a doctor can't be double-booked at the same time)
- Search appointments by patient
- Daily schedule by date
- Cancel appointments
- Sort appointments by date and time
- Data is saved in the browser (localStorage)

## Run it
Open `index.html` in any browser. No install needed.
